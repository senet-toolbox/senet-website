API Reference

Initialization

Two ways to create a Select:

// Flat list var select = Select(MyEnum).fromItems(&.{ ... }); // Grouped list var select = Select(MyEnum).init("Placeholder", &.{ Select(MyEnum).Group{ .title = "Group", .items = &.{ ... } }, });

Item Structure

Each item requires a value and label. Icon is optional.

.{ .value = MyEnum.option, .label = "Option Label", .icon = .icon_name }

Properties

Configure behavior after initialization.

select.trigger = "Placeholder text"; // Custom placeholder select.trigger_component = myFn; // Custom trigger component select.on_select = handleSelect; // Selection callback

Render Methods

Choose how to render the component.

select.render(); // Render trigger + dropdown together select.renderTrigger(); // Render trigger only select.renderSelect(); // Render dropdown only

Callback Signature

The on_select callback receives the select instance and selected item.

fn handleSelect(sel: *Select(MyEnum), item: *Select(MyEnum).Item) void { // item.value - the enum value // item.label - the display string // item.icon - optional icon }
