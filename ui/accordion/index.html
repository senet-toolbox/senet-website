A collection of ready-to-use button components built on top of Vapor. Copy and paste into your apps.

Button

Displays a button or a component that looks like a button.

Installation

Install the button component from your command line.

vapor add button

Usage

Import and use the Button component in your code.

const Button = @import("components/Button.zig").Button;

Examples

Primary

Button(handleClick, .{}) .background(.palette(.tint)) .children({ Text("Primary").end(); });

Secondary

Button(handleClick, .{}) .background(.transparent) .border(.round(.palette(.border_color_light), .all(8))) .children({ Text("Secondary").end(); });

With Icon

Button(handleClick, .{}) .children({ Icon(.arrow_right).end(); Text("Continue").end(); });

API Reference

The Button component accepts the following properties.

// Handler and arguments Button(handler_fn, .{ arg1, arg2 }) // Styling .background(.palette(.tint)) .border(.round(.palette(.border_color_light), .all(8))) .padding(.xy(16, 10)) .layout(.center) .spacing(8)
